# AI Portfolio Analyzer ML Service API Documentation

This document provides comprehensive API documentation for the Machine Learning (ML) Service component of the AI Portfolio Analyzer. This service is responsible for processing user-provided portfolio screenshots, extracting data using Optical Character Recognition (OCR), enriching it with real-time market data, and generating AI-driven insights and predictions.

---

## 1. Overview and Purpose

The AI Portfolio Analyzer is an innovative application designed to help users understand and optimize their investment portfolios. Users can upload screenshots of their brokerage accounts, and the system will automatically extract relevant information, fetch real-time market data, and provide intelligent analysis.

The ML Service is the core engine behind this functionality. Its primary responsibilities include:
*   **OCR (Optical Character Recognition):** Converting portfolio screenshots into machine-readable text.
*   **Portfolio Data Parsing:** Structuring the extracted text into a coherent portfolio representation (e.g., identifying tickers, share counts, average costs).
*   **Market Data Enrichment:** Fetching current prices, daily changes, and historical data for identified holdings from various financial APIs.
*   **AI Analysis:** Applying machine learning models to generate insights, risk assessments, diversification scores, performance outlooks, and actionable recommendations.

This API documentation details the endpoints exposed by the ML Service, allowing the backend (e.g., a Node.js Express server) or other clients to interact with its capabilities. The service is primarily written in Python using FastAPI.

---

## 2. API Endpoints

This section details all available API endpoints, their functionalities, parameters, return values, and usage.

### 2.1. GET /

**Overview:**
This is the root endpoint of the ML Service, providing basic information about the service's status, version, and the availability of its core internal components (like OCR). It serves as a quick health check and an entry point for discovering other available endpoints.

**Functions/Classes:**
This endpoint is handled by the `root` asynchronous function within `ml-service/main.py`, decorated with `@app.get("/")`.

```python
# ml-service/main.py
@app.get("/")
async def root():
    """Root endpoint"""
    # ... implementation ...
```

**Parameters:**
None.

**Return Values:**
A JSON object containing service metadata and status.

| Field                 | Type      | Description                                                                 |
| :-------------------- | :-------- | :-------------------------------------------------------------------------- |
| `message`             | `string`  | A descriptive message for the service.                                      |
| `version`             | `string`  | The current version of the ML Service.                                      |
| `status`              | `string`  | Indicates the operational status of the service (e.g., "running").          |
| `services_available`  | `boolean` | Overall readiness status of critical internal services (e.g., OCR, AI).     |
| `ocr_available`       | `boolean` | Specific status indicating if the OCR service component is initialized and ready. |
| `directory_structure` | `string`  | A hint about the internal directory structure of the service.               |
| `endpoints`           | `object`  | A dictionary listing other key API endpoints available.                     |
| `endpoints.health`    | `string`  | Path to the health check endpoint.                                          |
| `endpoints.portfolio_analysis` | `string` | Path to the main portfolio analysis endpoint.                               |
| `endpoints.portfolio_analyze` | `string` | An alternative or legacy path for portfolio analysis.                       |

**Usage Examples:**

**cURL:**
```bash
curl http://localhost:8000/
```

**Expected Response (JSON):**
```json
{
  "message": "AI Portfolio Analyzer ML Service",
  "version": "2.0.0",
  "status": "running",
  "services_available": true,
  "ocr_available": true,
  "directory_structure": "src/services/",
  "endpoints": {
    "health": "/health",
    "portfolio_analysis": "/api/ocr/parse-portfolio-with-market-data",
    "portfolio_analyze": "/api/portfolio/analyze"
  }
}
```

**Error Handling:**
This endpoint is designed to be highly resilient. In most cases, it will return a 200 OK response with the current status. A 500 Internal Server Error might occur only if the FastAPI application itself fails to start or encounters a critical unhandled exception during its initialization.

**Common Use Cases:**
*   **Service Monitoring:** Regularly pinging the root endpoint to ensure the ML service is up and running.
*   **Initial Connection Test:** Verifying connectivity from a client application.
*   **Endpoint Discovery:** Programmatically retrieving the paths to other API functionalities.

### 2.2. POST /api/ocr/parse-portfolio-with-market-data

**Overview:**
This is the primary and most comprehensive endpoint for analyzing a user's portfolio screenshot. It orchestrates the entire analysis pipeline: performing OCR on the uploaded image, parsing the extracted text into structured portfolio data, enriching this data with real-time market information, and finally generating AI-driven insights and recommendations.
